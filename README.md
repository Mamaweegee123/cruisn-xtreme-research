# Cruis’n Xtreme — Development Archive

An unofficial, community-oriented preservation and development archive. It is not affiliated with or endorsed by the games’ rights holders. The long-term vision is to connect Cruis’n World native recompilation, research into Cruis’n USA and Cruis’n Exotica, independent handheld experiments, Velocity GBA work, and a shared launcher while keeping every project’s maturity clear.

> This repository is a documentation-only research hub. It is not a game, full source backup, or buildable project.

## Project map

Repository destinations below are placeholders until approved repositories exist; they are not live URLs.

- [Cruis’n World Recompiled](https://github.com/OWNER/cruisn-world-recompiled) — most mature project; a local macOS build was mechanically played, but this public source candidate is incomplete and the binary is not cleared for distribution.
- [Cruis’n World 3DS ARM11](https://github.com/OWNER/cruisn-world-3ds) — incomplete software-RDP experiment; partial Azahar graphics/framebuffer evidence, no playable race.
- [Cruis’n World 3DS RT64](https://github.com/OWNER/cruisn-world-3ds-rt64) — separate incomplete feasibility experiment; RT64 bridge remains disconnected.
- [Cruis’n World Vita](https://github.com/OWNER/cruisn-world-vita) — experimental source; one device log records early runtime/graphics task activity, but visible gameplay is unverified.
- [Cruis’n Xtreme Launcher](https://github.com/OWNER/cruisn-xtreme-launcher) — local source-only developer preview; not a packaged player application.
- [Cruis’n Xtreme Research](https://github.com/OWNER/cruisn-xtreme-research) — this text-only hub.
