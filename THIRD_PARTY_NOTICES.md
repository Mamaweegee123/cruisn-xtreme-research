# Third-party notices and dependency limits

This hub contains no copied third-party implementation source. The PC runtime work references N64ModernRuntime (GPLv3), N64Recomp (MIT), RT64 (MIT with nested dependency notices), SDL2-compat (identified locally as zlib-style), and platform/build tooling. Exact versions, linkage, and complete binary notices remain a separate release-engineering task.

The launcher source uses Qt for Python/PySide6 and PyInstaller; packaged distribution obligations depend on actual modules and packaging configuration. No app bundle is present here.

Velocity depends on GBARecomp, identified in project records as PolyForm Noncommercial 1.0.0. No Velocity source, code, replay, generated output, ROM, BIOS, or executable is included in this repository. Do not treat the hub’s MIT documentation scope as changing any dependency terms.
