# Contributing

Start with the project-specific status and blockers before writing code. Keep platform experiments separate, retain evidence with exact build/source identifiers, and distinguish live behavior from logs, synthetic tests, and replay simulations.

Do not add commercial ROMs, saves, extracted models/textures/audio, generated guest code, replay inputs, binaries, checkpoints, or private captures. Use placeholders for repository destinations until an owner approves publication. Do not imply the projects are official or endorsed.

The associated source exports have project-specific and upstream license boundaries. This hub does not license any game content or third-party source.
